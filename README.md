# ⭐ Featured Projects

## 🤖 Nova

### Локальный голосовой AI-ассистент на Python

Мой основной и самый большой pet-project.

Nova умеет работать с голосовым вводом, локальной LLM, командами, внешними API, долговременной памятью и контекстом.

Проект строится как полноценная модульная система:

```text
🎙️ Voice
   ↓
📝 Whisper
   ↓
🧠 Context Manager
   ↓
🤵 Butler
   ↓
⚙️ Command Handler
   ↓
🗄️ Memory / API / Tools
   ↓
💬 Responder
   ↓
🔊 TTS
```

### Что использую

`Python` · `SQLite` · `SQLAlchemy` · `llama.cpp` · `Qwen` · `Whisper` · `REST API`

### Что изучаю на проекте

* архитектуру Python-приложений;
* взаимодействие компонентов;
* работу с локальными LLM;
* API и интеграции;
* хранение и обработку контекста;
* долгосрочную память;
* проектирование инструментов и команд.

👉 **[Посмотреть Nova](https://github.com/BoCXoD-man/Nova)**
