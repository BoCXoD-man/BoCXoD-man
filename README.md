# ⭐ Featured Projects

## 🤖 Nova

### Локальный голосовой AI-ассистент на Python

Мой основной и самый большой pet-project.

Nova объединяет голосовой ввод, локальную LLM, команды, внешние API, долговременную память и работу с контекстом.

Проект строится как модульная система:

```text
🎙️ Voice
   ↓
📝 Whisper
   ↓
🧠 Context Manager
   ↓
🤵 Butler
   ↓
⚙️ Command Handler
   ↓
🗄️ Memory / API / Tools
   ↓
💬 Responder
   ↓
🔊 TTS
```

### Стек

`Python` · `SQLite` · `SQLAlchemy` · `llama.cpp` · `Qwen` · `Whisper` · `REST API`

### Что реализовано

* 🎙️ голосовой ввод и распознавание речи;
* 🧠 работа с локальной LLM;
* ⚙️ обработка структурированных команд;
* 🗄️ долговременная память;
* 👤 хранение информации о пользователе и связанных людях;
* 🔎 выбор релевантного контекста;
* 🌐 интеграция с внешними API;
* 🔊 синтез речи;
* 📝 логирование и конфигурация через `.env`.

### Что изучаю на проекте

* архитектуру Python-приложений;
* взаимодействие независимых компонентов;
* проектирование API и инструментов;
* работу с локальными LLM;
* хранение и обработку контекста;
* проектирование памяти;
* организацию большого pet-project.

👉 **[Посмотреть Nova](https://github.com/BoCXoD-man/Nova)**
